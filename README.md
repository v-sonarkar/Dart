# Dart Examples & Exercises

A collection of small Dart example programs organized by topic. These files are intended for learning Dart language features and core concepts.

## Project Structure

- `AsynchronousProgramming/` — Examples demonstrating Futures and Streams.
  - `Future/` — `main.dart`, `method1.dart`, `method2.dart`, `method3.dart`
  - `Stream/` — `method.dart`
- `conditional&Loops/` — Conditional statements and loops (`if.dart`, `logicaloperator.dart`, `loops.dart`, `switch.dart`).
- `enum/` — `enum.dart` (enum examples).
- `Exceptionhandling/` — Exception handling and file examples (`except.dart`, `file.dart`).
- `maps/` — Map usage examples (`main.dart`).
- `OOPs/` — Classes and objects (`classes.dart`, `objects.dart`).
- `PillarsofOOPs/` — Organized by OOP pillars:
  - `Abstraction/` — `main.dart`, `person.dart`
  - `Inheritance/` — `main.dart`, `person.dart`, `student.dart`
  - `Polymorphism/`
- `Variables,DataTypes&Functions/` — Basics and functions (`first.dart`, `function.dart`, `list.dart`).

## Prerequisites

- Install the Dart SDK: https://dart.dev/get-dart

## Running examples

From the project root (`Dart`), run a single example with the Dart CLI. Examples:

PowerShell (paths with special characters like `&` should be quoted):

```
dart run "conditional&Loops/switch.dart"
dart run AsynchronousProgramming/Future/main.dart
```

Or in a terminal/IDE, open the file and run it with your editor's Dart runner.
